## Design Process

When creating or redesigning any frontend:

1. **Read the brief** — Understand what's being built, for whom, and what mood/style is needed
2. **Consult core skills** — Read the relevant SKILL.md files from the categories above that match the task
3. **Plan before coding** — Create a design token system (colors, typography, spacing) before writing HTML/CSS
4. **Anti-slop check** — Avoid AI defaults: generic gradients, centered hero + 3 cards + CTA, Inter font, template layouts
5. **Self-critique** — Review your output against the design principles before delivering
6. **Responsive & accessible** — Every design must work on mobile and respect accessibility standards

## Key Anti-Patterns to Avoid

- Generic AI purple/blue gradients
- Hero → 3 feature cards → CTA → footer (every time)
- Inter/system font as default without deliberation
- Invented metrics ("10x faster", "+47% conversion")
- Glassmorphism on everything
- Dark mesh backgrounds
- Numbered markers (01/02/03) when content isn't sequential
- Template-swap designs where only colors change between projects
